`seoul_gu.geojson` is a compact copy of
[`southkorea/seoul-maps` KOSTAT 2013 municipal boundaries](https://github.com/southkorea/seoul-maps/blob/master/kostat/2013/json/seoul_municipalities_geo_simple.json).
The source repository credits Lucy Park and licenses the data under Apache 2.0.
The license text is included in `seoul_gu.LICENSE.txt`.
This copy is bundled so the map can render without a GitHub request at startup.
